# AI播客鸿蒙APP - 快速启动指南

## 前置条件

1. **后端服务已启动**
   ```bash
   # 在项目根目录下
   python run_api_server.py --host 0.0.0.0 --port 8000
   ```

2. **获取服务器IP地址**
   - Windows: `ipconfig` 查看IPv4地址
   - Mac/Linux: `ifconfig` 查看IP地址
   - 确保手机和电脑在同一局域网

## 配置步骤

### 1. 修改API地址

打开文件：`podcasters/components/lib_api/src/main/ets/services/PodcastService.ets`

找到第11行，修改为您的服务器IP地址：

```typescript
export class PodcastConfig {
  // 将此处替换为您的实际服务器地址
  static readonly API_BASE_URL: string = 'http://192.168.1.100:8000'; // 修改这里
  static readonly API_TIMEOUT: number = 300000;
}
```

### 2. 测试连接

启动后端服务后，在浏览器中访问：
- 健康检查: http://您的IP:8000/health
- API文档: http://您的IP:8000/docs

确保可以正常访问。

## 运行APP

1. **打开DevEco Studio**
2. **导入项目**: 打开 `podcasters` 目录
3. **配置签名**: 按照HarmonyOS开发指南配置应用签名
4. **连接设备**: 使用USB连接HarmonyOS设备或启动模拟器
5. **运行应用**: 点击运行按钮

## 使用流程

### 方式1: 多角色互动播客

1. 打开APP，点击底部"AI办公"标签
2. 点击"AI播客"卡片
3. 选择"多角色互动播客"
4. 输入播客文本，例如：
   ```
   [角色A]你好，今天我们来聊聊人工智能的发展。
   [角色B]是的，人工智能确实是一个热门话题。
   [角色A]你觉得人工智能未来会如何发展？
   [角色B]我认为人工智能将会改变我们的生活方式。
   ```
5. 为每个角色选择音色文件（WAV格式）
6. 点击"开始生成"
7. 等待生成完成（通常需要1-5分钟）
8. 在结果页面播放音频和查看脚本

### 方式2: 自定义角色播客

1. 选择"自定义角色播客"
2. 输入播客主题（可选），例如："人工智能的未来"
3. 为每个角色配置：
   - 角色名称：例如"小明"、"小红"
   - 身份/职业：例如"AI研究员"、"科技记者"
   - 核心性格：例如"严谨"、"幽默"
   - 选择音色文件
4. 点击"开始生成"

### 方式3: 主题深度播客

1. 选择"主题深度播客"
2. 输入播客主题，例如："人工智能对社会的影响"
3. 选择角色数量（2个或3个）
4. 选择深度级别（深度/中等/浅层）
5. 为每个角色选择音色文件
6. 点击"开始生成"

## 音色文件准备

### 文件要求
- **格式**: WAV格式（推荐）
- **时长**: 5-30秒
- **质量**: 清晰、无噪音
- **大小**: 建议不超过10MB

### 获取音色文件
1. 使用录音软件录制
2. 从网络下载示例音频
3. 使用TTS工具生成参考音频

## 常见问题

### Q1: 无法连接到服务器
**解决方案**:
- 检查服务器是否正在运行
- 检查IP地址配置是否正确
- 检查手机和电脑是否在同一网络
- 检查防火墙设置

### Q2: 文件选择失败
**解决方案**:
- 确保已授予文件访问权限
- 尝试使用其他文件格式
- 检查文件是否存在

### Q3: 生成失败
**解决方案**:
- 检查网络连接
- 检查服务器日志
- 检查API密钥配置
- 检查音色文件格式

### Q4: 音频播放失败
**解决方案**:
- 检查音频数据是否完整
- 检查设备是否支持音频播放
- 尝试重新生成
