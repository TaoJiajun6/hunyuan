# 音色文件配置指南

## 概述

Web端现在支持使用预设音色文件，用户可以直接从预设列表中选择音色，无需手动上传。音色文件会自动上传到云存储。

## 目录结构

```
web/
├── public/
│   └── voices/          # 音色文件存放目录
│       ├── male_01.wav
│       ├── female_01.wav
│       └── ...
└── src/
    └── config/
        └── voices.ts     # 音色配置文件
```

## 配置步骤

### 1. 准备音色文件

将音色音频文件放在 `public/voices/` 目录下：

```bash
web/public/voices/
├── male_01.wav      # 男声-沉稳
├── male_02.wav      # 男声-活泼
├── female_01.wav    # 女声-温柔
├── female_02.wav    # 女声-知性
└── neutral_01.wav   # 中性-自然
```

**文件要求：**
- 格式：`.wav`, `.mp3`, `.m4a`, `.flac`, `.ogg`, `.aac` 等
- 推荐：`.wav` 或 `.mp3`
- 大小：建议每个文件不超过 10MB
- 时长：建议 3-10 秒的音频样本

### 2. 配置音色信息

编辑 `src/config/voices.ts`，添加或修改音色配置：

```typescript
export const VOICE_OPTIONS: VoiceOption[] = [
  {
    id: 'voice_male_01',
    name: '男声-沉稳',
    description: '沉稳大气的男声，适合新闻、知识类播客',
    file: 'male_01.wav',  // 必须与文件名完全匹配
    gender: 'male',
    style: '沉稳',
  },
  // 添加更多音色...
];
```

**配置说明：**
- `id`: 唯一标识符，建议使用 `voice_` 前缀
- `name`: 显示名称，会显示在UI上
- `description`: 描述信息（可选）
- `file`: 文件名，必须与 `public/voices/` 目录下的文件名完全匹配
- `gender`: 性别分类（可选），用于筛选
- `style`: 风格描述（可选），会显示为标签

### 3. 使用音色选择器

音色选择器已集成到以下页面：
- **多角色互动播客** (`MultiRolePage.tsx`)
- **自定义角色播客** (`CharacterPage.tsx`)
- **主题深度播客** (`DeepPage.tsx`)

用户选择音色后，系统会：
1. 从 `public/voices/` 目录加载音色文件
2. 自动上传到云存储
3. 获取云存储URL并用于播客生成

## 功能特性

### 音色预览

用户可以在选择前预览音色：
- 点击播放按钮试听音色
- 再次点击停止播放
- 同时只能播放一个音色

### 音色选择

- 显示所有可用音色列表
- 显示音色名称、描述和风格标签
- 已选择的音色会高亮显示
- 支持快速切换音色

### 自动上传

- 选择音色后自动上传到云存储
- 显示上传进度提示
- 上传成功后自动使用云存储URL

## 注意事项

1. **文件路径**: 确保 `file` 字段与 `public/voices/` 目录下的文件名完全匹配
2. **文件格式**: 支持常见音频格式，但建议使用 `.wav` 或 `.mp3`
3. **文件大小**: 建议每个文件不超过 10MB，避免上传时间过长
4. **网络连接**: 音色文件需要上传到云存储，确保网络连接正常
5. **文件质量**: 使用高质量的音频文件，避免噪音和失真

## 故障排除

### 音色文件无法加载

- 检查文件是否存在于 `public/voices/` 目录
- 检查 `voices.ts` 中的 `file` 字段是否与文件名匹配
- 检查文件格式是否支持
- 查看浏览器控制台是否有错误信息

### 音色上传失败

- 检查网络连接
- 检查API服务器是否正常运行
- 检查文件大小是否超过限制
- 查看浏览器控制台错误信息

### 音色预览无法播放

- 检查浏览器是否支持音频格式
- 检查文件是否损坏
- 尝试使用其他浏览器
