# Web端快速启动指南

## 快速开始

### 1. 安装依赖

```bash
cd web
npm install
```

### 2. 配置API地址（可选）

默认已配置为云服务器地址 `http://123.207.14.127:8000`

如果需要修改API服务器地址，创建 `.env` 文件：

```env
VITE_API_BASE_URL=http://your-api-server:8000
```

### 3. 启动开发服务器

```bash
npm run dev
```

应用将在 `http://localhost:3000` 启动

### 4. 构建生产版本

```bash
npm run build
```

构建产物在 `dist` 目录

## 功能说明

### 主页面

- **AI播客**: 播客功能主页，包含功能卡片和最近播客列表
- **我的**: 用户设置页面（待实现）

### 播客功能

1. **多角色互动播客**
   - 支持多种输入类型：文字、文件、公众号、网页等
   - 支持指令控制
   - 支持多个角色音色配置

2. **自定义角色播客**
   - 自定义角色信息（名称、身份、性格、说话风格）
   - 支持2-4个角色
   - 必需提供文本素材

3. **主题深度播客**
   - 基于主题自动生成内容
   - 可选择深度级别
   - 支持1-3个角色

## 注意事项

1. **文件上传**: 所有文件（文本和音频）都需要先上传到云存储
2. **进度显示**: 使用HTTP轮询方式获取任务进度
3. **浏览器兼容性**: 建议使用现代浏览器（Chrome、Firefox、Edge等）

## 故障排除

### 无法连接到API服务器

- 检查API服务器是否运行
- 检查 `VITE_API_BASE_URL` 配置是否正确
- 检查浏览器控制台是否有CORS错误

### 文件上传失败

- 检查文件大小限制
- 检查网络连接
- 查看浏览器控制台错误信息

### 进度不更新

- 检查任务ID是否正确
- 检查API服务器是否支持进度查询接口
- 查看浏览器控制台网络请求
