# 音色文件目录

此目录用于存放预设的音色音频文件。

## 文件要求

- **格式**: 支持 `.wav`, `.mp3`, `.m4a`, `.flac`, `.ogg`, `.aac` 等常见音频格式
- **推荐格式**: `.wav` 或 `.mp3`
- **文件大小**: 建议每个文件不超过 10MB
- **时长**: 建议 3-10 秒的音频样本

## 使用方法

1. 将音色音频文件放在此目录下
2. 在 `src/config/voices.ts` 中配置音色信息
3. 确保 `file` 字段与文件名匹配

## 示例

```
public/voices/
├── male_01.wav      # 男声-沉稳
├── male_02.wav      # 男声-活泼
├── female_01.wav    # 女声-温柔
├── female_02.wav    # 女声-知性
└── neutral_01.wav   # 中性-自然
```

## 注意事项

- 音色文件会在用户选择时自动上传到云存储
- 确保音色文件质量良好，避免噪音和失真
- 建议使用统一的采样率和位深度（如 44.1kHz, 16bit）
