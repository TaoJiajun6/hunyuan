# Web 页面访问说明

## 重要说明

**8000 是后端 API 服务器的端口**。Web 页面是通过后端 API 服务器提供的静态文件服务，不需要单独的前端服务器。

## 访问方式

启动后端 API 服务器后，可以通过以下方式访问 Web 页面：

### 1. 通过根路径访问（推荐）

```
http://localhost:8000/
```

或者如果部署在远程服务器：

```
http://your-server-ip:8000/
```

### 2. 直接访问 Web 页面

```
http://localhost:8000/web/index.html
```

**注意**：如果后端服务器运行在其他端口，请相应修改端口号。

## 启动后端 API 服务器

后端 API 服务器默认运行在 **8000 端口**，启动后即可同时提供 API 服务和 Web 页面。

### 方式一：直接运行

```bash
python -m hunyuan_podcast.api_server
```

### 方式二：使用 uvicorn

```bash
uvicorn hunyuan_podcast.api_server:app --host 0.0.0.0 --port 8000
```

### 方式三：指定参数（修改端口）

如果需要使用其他端口（例如 8080）：

```bash
python -m hunyuan_podcast.api_server --host 0.0.0.0 --port 8080
```

然后访问：`http://localhost:8080/`

## 功能说明

Web 页面提供以下功能：

1. **多角色互动播客** - 将文本素材转化为多角色自然互动的播客音频
2. **自定义角色播客** - 根据用户自定义的角色人设和音色生成播客
3. **主题深度播客** - 基于指定主题生成有深度、引发思考的播客音频
4. **文本分析** - 分析文本素材，推断播客名称、主题、角色设定和互动场景

## 注意事项

1. **后端 API 服务器必须运行** - Web 页面通过后端服务器提供，端口默认是 8000
2. **同一服务器** - Web 页面和 API 服务运行在同一个服务器和端口上
3. **文件上传** - 音色文件会转换为 base64 编码后发送到服务器
4. **浏览器兼容性** - 建议使用现代浏览器（Chrome、Firefox、Edge 等）
5. **CORS 配置** - API 服务器已配置 CORS，允许跨域请求

## 故障排除

### 无法访问 Web 页面

1. 检查后端 API 服务器是否正在运行
2. 检查端口是否正确（默认 8000，这是后端服务器的端口）
3. 确认访问的 URL 端口与后端服务器启动的端口一致
4. 检查防火墙设置
5. 查看服务器日志是否有错误

### 静态文件无法加载

1. 检查 `hunyuan_podcast/web/` 目录是否存在
2. 检查文件路径是否正确
3. 查看浏览器控制台的网络请求错误

### API 请求失败

1. 检查浏览器控制台的错误信息
2. 检查后端 API 服务器日志
3. 确认 API 端点是否正确（`/api/v1/podcast/*`）
4. 确认后端服务器端口与访问的端口一致
