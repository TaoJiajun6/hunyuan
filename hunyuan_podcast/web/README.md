# Web 页面访问说明

## 架构说明

**前后端分离架构**：
- **前端服务器**：运行在 **8001 端口**，提供 Web 页面
- **后端 API 服务器**：运行在 **8000 端口**，提供 API 服务

前端通过 HTTP 请求调用后端 API。

## 启动步骤

### 1. 启动后端 API 服务器（端口 8000）

```bash
# 方式一：直接运行
python -m hunyuan_podcast.api_server --host 0.0.0.0 --port 8000

# 方式二：使用 uvicorn
uvicorn hunyuan_podcast.api_server:app --host 0.0.0.0 --port 8000
```

### 2. 启动前端服务器（端口 8001）

```bash
# 方式一：使用 Python 简单服务器（推荐）
python hunyuan_podcast/web/server.py --port 8001

# 方式二：使用 Python 内置服务器
cd hunyuan_podcast/web
python -m http.server 8001

# 方式三：使用其他静态文件服务器（如 nginx）
```

## 访问方式

启动前端和后端服务器后：

### 访问 Web 页面

```
http://localhost:8001/
```

或者如果部署在远程服务器：

```
http://your-server-ip:8001/
```

**注意**：
- 前端服务器运行在 **8001 端口**
- 后端 API 服务器运行在 **8000 端口**
- 前端会自动连接到后端 API（`http://localhost:8000`）

## 配置说明

### API 服务器地址配置

前端代码会自动检测并连接到后端 API：

- **本地开发**：自动连接到 `http://localhost:8000`
- **远程部署**：自动连接到 `http://{服务器IP}:8000`

如果需要修改后端 API 地址，可以编辑 `script.js` 文件中的 `API_BASE_URL` 配置。

## 功能说明

Web 页面提供以下功能：

1. **多角色互动播客** - 将文本素材转化为多角色自然互动的播客音频
2. **自定义角色播客** - 根据用户自定义的角色人设和音色生成播客
3. **主题深度播客** - 基于指定主题生成有深度、引发思考的播客音频
4. **文本分析** - 分析文本素材，推断播客名称、主题、角色设定和互动场景

## 注意事项

1. **必须同时启动前后端** - 前端（8001）和后端（8000）都需要运行
2. **端口配置** - 前端默认 8001，后端默认 8000，不要冲突
3. **文件上传** - 音色文件会转换为 base64 编码后发送到后端服务器
4. **浏览器兼容性** - 建议使用现代浏览器（Chrome、Firefox、Edge 等）
5. **CORS 配置** - 后端 API 服务器已配置 CORS，允许跨域请求
6. **网络连接** - 确保前端可以访问后端 API 服务器

## 故障排除

### 无法访问 Web 页面

1. 检查前端服务器是否正在运行（端口 8001）
2. 检查后端 API 服务器是否正在运行（端口 8000）
3. 确认访问的 URL 端口是 8001（前端端口）
4. 检查防火墙设置
5. 查看服务器日志是否有错误

### 无法连接到后端 API

1. 检查后端 API 服务器是否运行在 8000 端口
2. 检查浏览器控制台是否有 CORS 错误
3. 检查网络连接，确保前端可以访问后端
4. 查看后端服务器日志

### 静态文件无法加载

1. 检查 `hunyuan_podcast/web/` 目录是否存在
2. 检查文件路径是否正确
3. 查看浏览器控制台的网络请求错误

### API 请求失败

1. 检查浏览器控制台的错误信息
2. 检查后端 API 服务器日志
3. 确认 API 端点是否正确（`/api/v1/podcast/*`）
4. 确认后端服务器端口与访问的端口一致
